Risiko og ansvar

Læringsmål: Gjenkjenne de viktigste risikoene og forstå ditt ansvar når Claude Code brukes.

Tre risikoer du må håndtere

Handlinger på dine vegne

Claude kan utføre handlinger gjennom terminaltilgang og automatiserte arbeidsflyter. Du er ansvarlig for handlingene og må kontrollere resultatet. Gi bare tilgangene og selvstendigheten som trengs for oppgaven; for vide tillatelser øker risikoen for uønskede handlinger.

Feil eller mangelfulle forslag

Kode og forslag kan virke riktige, men inneholde feil, sikkerhetshull eller mangler. Alt innhold må kvalitetssikres før bruk.

Deling av informasjon

Informasjon som deles med Claude, inngår i arbeidskonteksten. Del bare informasjon det er tillatt og nødvendig å bruke. Neste modul går nærmere inn på data og hemmeligheter.

Du har ansvaret

Claude Code er et hjelpemiddel, ikke en erstatning for menneskelig vurdering.

  • Du har alltid ansvar for kvalitet, sikkerhet og korrekthet, også for KI-generert kode.
  • Lever bare kode du forstår, kan forklare og kan vedlikeholde.
  • All kode skal kvalitetssikres gjennom tester, lint, build og kodegjennomgang (code review).
  • Bruk KI som støtte, ikke som fasit.

Vær ekstra kritisk når konsekvensene er store

Dette gjelder særlig sikkerhets- eller forretningskritisk kode, arkitektur, produksjonssystemer, tilgangsstyring og sensitiv informasjon. Behandle forslag fra Claude som utkast og vurder dem grundig.

Kort oppsummert

Begrens tilganger, kontroller handlinger og kvalitetssikre alle resultater. Ansvaret ligger hos deg, også når KI har skrevet koden.
