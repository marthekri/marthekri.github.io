MCP-servere

Læringsmål: Forstå at tilkoblinger kan utvide agentens tilganger, og vite hvor godkjent bruk må avklares.

Godkjent bruk må avklares i retningslinjene

Utkastet fastsetter ikke hvilke MCP-servere som er tillatt. Se de offisielle Retningslinjer for Claude Code i <organization> for godkjent bruk. Denne modulen gir ingen godkjenning av servere eller tilkoblinger.

Hvorfor er tilkoblinger viktige?

MCP (Model Context Protocol) kan koble Claude Code til eksterne verktøy og datakilder. Tilkoblingen kan gi agenten flere muligheter til å lese informasjon eller utføre handlinger, avhengig av hvilke tilganger som gis.

De samme prinsippene gjelder som ellers: begrens tilgangene til det nødvendige, forstå hva som kan deles, og kontroller handlinger og resultater.

Mulige risikoer

Dette er generelle risikoforhold, ikke en beskrivelse av konkrete servere i <organization>:

  • Informasjon kan bli delt med en tjeneste som ikke skal motta den.
  • For vide tilganger kan gjøre det mulig å lese eller endre mer enn oppgaven krever.
  • Feilaktige eller uønskede handlinger kan utføres gjennom tilkoblede verktøy.

Åpent før kurset ferdigstilles

Det må avklares hvor mye veiledning om MCP-servere som skal inngå i kurset, og hva som bare skal omtales i retningslinjene. Konkrete eksempler på risiko og misbruk er også et åpent punkt i utkastet.

Kort oppsummert

En tilkobling kan utvide både muligheter og risiko. Avklar tillatt bruk i de offisielle retningslinjene før du kobler til en MCP-server.
