Hva er Claude Code?

Læringsmål: Forstå hva verktøyet kan gjøre, og hvorfor agentiske verktøy krever bevisst bruk.

Et agentisk kodeverktøy

Claude Code er et agentisk kodeverktøy for programvareutvikling. Det kan analysere kode, gjøre endringer i filer, kjøre kommandoer og bistå med utviklingsoppgaver på tvers av flere filer og verktøy.

At verktøyet er agentisk, betyr her at det kan utføre handlinger på dine vegne, ikke bare foreslå tekst eller kode.

Hva kan det brukes til?

  • Utvikle funksjonalitet.
  • Rette kodefeil.
  • Automatisere utviklingsoppgaver.

Fordi Claude Code kan arbeide på tvers av hele kodebasen og utføre handlinger på dine vegne, må du forstå både mulighetene og risikoene ved bruk.

Hvor kan det brukes?

Du kan få tilgang til Claude Code gjennom terminalen, et utviklingsmiljø (IDE), en skrivebordsapp eller nettleseren. Hvilken bruk som er tillatt i Vy, må vurderes opp mot de offisielle retningslinjene.

Kort oppsummert

Claude Code kan både foreslå og handle. Det gjør verktøyet nyttig, men fritar deg ikke fra å forstå og kontrollere resultatene.
