Velkommen til kurset

Bli kjent med Claude Code og de viktigste rammene for bruk i <organization> – fra muligheter og begrensninger til risiko og eget ansvar.

Les sammen med de offisielle retningslinjene

Dette er et kursutkast og foreslått obligatorisk lesestoff før lisens tildeles. Det er ikke de fullstendige retningslinjene og erstatter dem ikke. De offisielle Retningslinjer for Claude Code i <organization> finnes i tillegg og skal også leses.

Lenke til retningslinjene og rutinen for bekreftelse er ikke avklart i dette utkastet. Videre lesing og åpne avklaringer omtales i siste modul.

Dette skal du lære

  • Forstå hva Claude Code kan gjøre, og hvor verktøyet har begrensninger.
  • Gjenkjenne risiko og ta ansvar for handlinger og kode.
  • Begrense deling av informasjon og tilgang til data og verktøy.
  • Bruke KI til avgrensede oppgaver og kvalitetssikre resultatene.

Kurset er rettet mot utviklere som skal bruke Claude Code i <organization>. Les én side om gangen, og bruk Forrige og Neste for å gå gjennom kurset.

Kursmoduler

  1. 1. Introduksjon

    Hva Claude Code er, hva det kan brukes til, og hvordan du får tilgang.

  2. 2. Risiko og ansvar

    Handlinger på dine vegne, feilaktige forslag og ditt ansvar for kvalitet og sikkerhet.

  3. 3. Data og informasjon

    Hva som ikke skal deles, og hvordan du skjermer filer og hemmeligheter.

  4. 4. MCP-servere

    Tilganger, mulige risikoer og avklaringer som hører hjemme i retningslinjene.

  5. 5. Beste praksis

    Gode bruksområder og en arbeidsmåte med tydelige rammer og kontroll.

  6. 6. Bekreftelse og neste steg

    Oppsummering, videre lesing og forslag til bekreftelse på gjennomført lesing.
